# AI Usage Statement

In accordance with course academic integrity guidelines, this document discloses how Artificial Intelligence tools were utilized during the development of this project.

## Scope of AI Assistance
- **Repository Setup & Documentation Formatting**: AI was utilized to draft repository structure templates, markdown documentation checklists, and task breakdowns based on the course final project rubric.
- **Code Assistance**: AI served as an advisory and pair-programming assistant for debugging OpenGL setup issues, reviewing mathematical formulas for matrix transformations, and providing guidance on GLSL syntax.
- **Verification & Ownership**: All source code and shaders were reviewed, manually verified, compiled, and tested by team members (Bekzat Duisenbek and Asylbek). No automated black-box code generation was accepted without full understanding of the underlying computer graphics principles.
